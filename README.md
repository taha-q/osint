# OSINT

A collection of OSINT tools.

## Overview

This repository contains small Python-based tools for open-source intelligence workflows.

## Structure

- Keep each tool focused and easy to run.

## Getting started

```bash
python --version
```

Clone the repository and explore the files in the project root.

```bash
git clone https://github.com/taha-q/osint.git
cd osint
```
